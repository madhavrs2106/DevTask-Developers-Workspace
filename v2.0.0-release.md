## DevTask v2.0.0

Full-stack developer productivity & task tracker with social features, co-learning rooms, quizzes, and anti-cheat.

### New Features Since v1.0.0

**User System**
- Username system with unique handles
- Public user profiles at `/u/:username`
- User search — find developers by name or username
- Follow / Unfollow system with followers & following counts
- Follower & following list page
- Delete account with name confirmation

**Co-Learning Rooms**
- Create & join shared study spaces with invite codes
- Public / Private rooms with password protection
- Room settings — edit name, description, invite code, delete room
- Room header with accent color, visibility badge, member count, streak
- Syllabus tab — admin add/delete topics, member completion tracking with avatars
- Discussions tab — threaded replies, filter by topic (General or specific topic)
- Members tab — see all members with roles
- Notes tab (removed) / Focus tab (removed)

**Quizzes**
- Full quiz system — admin creates quizzes with MCQ & numerical questions
- Draft & Published states with publish/unpublish controls
- Admin can edit draft quizzes (title, description, questions, answers)
- Quiz taking with answer submission
- Auto-grade for MCQ, manual grading for numerical
- Admin submissions view — expand/collapse per member, search, sort by percentage
- Quiz Result view — question-by-question table with correct/your answer
- Multi-line question support
- Max 20 questions per quiz

**Quiz Anti-Cheat**
- Tab switch detection with warning overlay
- Window blur detection (switching apps)
- Screenshot blocking (PrintScreen, Alt+PrintScreen)
- DevTools blocking (Ctrl+Shift+I/J)
- View source blocking (Ctrl+U)
- Print & save blocking (Ctrl+P, Ctrl+S)
- Right-click disabled
- Text selection disabled (reduces Google Lens)
- Fullscreen enforcement
- **1 violation = immediate lock** — persisted in database
- Locked users see "Locked — contact admin" instead of "Take Quiz"
- Lock status synced instantly (no refresh needed)

**Quiz Lock Admin Controls**
- Locked Members section in admin quiz view (after submissions)
- **Retake** button (green) — deletes submission + unlocks, member can retry
- **Submit** button (red) — creates graded submission with score 0 + unlocks

**Leaderboard**
- New tab between Discussions & Members
- Ranked table by average quiz score (medals for top 3)
- Shows quizzes taken, total score, percentage
- Color-coded: green ≥80%, amber ≥50%, red <50%
- Admin excluded from rankings

**Dashboard**
- Hours studied chart (weekly, Monday–Sunday)
- Courses studied chart
- Analytics backend endpoint

**UI/UX**
- Dark mode forced (no light mode toggle)
- Footer removed
- Task Board fixed-height columns with vertical scroll
- Sidebar highlights Task Board for both `/board` and `/tasks`
- Find Devs page with suggested accounts
- Profile pictures everywhere (avatar fallback with initials)
- Dropdown component for consistent select styling
- Android responsiveness fixes
- Syllabus green glow for completed topics

**Deployment**
- Render blueprint with PostgreSQL
- Auto-seed on first boot (`AUTO_SEED=true`)
- SQLite for local development
- Vite dev proxy for `/api` and `/uploads`
- Server auto-creates uploads directory
